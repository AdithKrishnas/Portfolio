## 🌐 1-Click Deployment to GitHub Pages

The portfolio is built with **zero build steps, zero npm packages, and zero server runtimes**. It is 100% native static HTML5, CSS3, and modern JavaScript, making it ultra-reliable and lightning-fast on GitHub Pages.

### Quick Setup:
1. Create a repository on [GitHub](https://github.com/new) (e.g., `portfolio` or `adithkrishnas.github.io`).
2. Run the following commands in this directory:
   ```bash
   git init
   git add .
   git commit -m "Launch AdithKrishna S. Digital Marketer Portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
3. In your GitHub repo:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select branch **`main`** and folder **`/(root)`**, then click **Save**.
4. Your site will be live in ~60 seconds at `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`!
